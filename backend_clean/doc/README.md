# 时空匠影 · 答辩文档（Word）

本目录仅维护三份 **Word 文档**，内容与当前 `heritage_mergen` 代码库一致。

| 文件 | 说明 |
|------|------|
| `1_时空匠影_比赛答辩项目介绍.docx` | 项目定位、八大模块、技术亮点、部署 |
| `2_时空匠影_前后端技术模块与代码说明.docx` | 技术栈、目录、路由、数据流、SSE、数据库 |
| `3_时空匠影_AI_Agent赛道专家答辩模拟问答.docx` | Agent 赛道 12 题答辩 Q&A |

## 重新生成 Word

修改 `build_docx.py` 内正文后执行：

```bash
cd backend_clean/doc
python build_docx.py
```
