# 时空匠影 · 项目文件结构说明

> 更新：2026-11-06。用于快速认路；细节以各目录 README 与源码为准。

## 仓库总览

```
heritage_mergen/
├── backend_clean/          # Flask API（核心业务）
├── vue-ep-frontend/        # Vue 3 + Element Plus 前端
├── docs/                   # 答辩文档、脚本、本说明与优化路线图
├── scripts/                # 仓库级辅助脚本（文档生成、补丁等）
├── 素材/                   # 本地演示素材（一般不入库逻辑）
├── .cursor/                # Cursor 规则与 skills（含登录页保护、优化路线图）
├── .agents/ · .claude/     # Agent skills 镜像（unslop 等）
└── README.md               # 快速开始与环境变量
```

**可忽略 / 勿当源码：** `node_modules/`、`dist/`、`__pycache__/`、`.idea/`、根目录 `debug.log`、未跟踪的临时 extract 文本。

## 后端 `backend_clean/`

| 路径 | 作用 |
|------|------|
| `app.py` | 应用入口 |
| `api/routes.py` | HTTP 路由聚合（对话、地图、识图等） |
| `core/` | `config.py` 配置、`models.py` 模型、`auth_utils.py` 鉴权、`exts.py` 扩展 |
| `shared/utils.py` | 高德/星火/智谱/检索等横切工具 |
| `features/agent/` | **Agent 核心**：`engine.py` 循环、`tools.py` 工具、`parse.py` 解析与推荐、`profile.py` 画像 |
| `features/graph/` | 知识图谱、Text2SQL、`rag.py`、节点/payload |
| `features/map/` | 路线规划等 |
| `features/revive/` | 数字焕新 / 作品入库 |
| `features/quiz/` · `report/` · `community/` | 答题、研学报告、打卡社区 |
| `features/demo/` | `DEMO_MODE` 预置数据与演示回复 |
| `chroma_db/` | 预构建向量库（体积较大，一般已入库） |
| `clean_nodes.json` · `clean_edges.json` | 图谱清洗数据 |
| `scripts/` | `build_rag_db.py`、`import_to_mysql.py`、密钥探测等 |
| `tests/` | 单元测试（Agent parse、图谱、星火错误等） |
| `doc/` | 答辩 docx 与 `build_docx.py`（与根 `docs/` 有部分重叠） |
| `.env` / `.env.example` | 密钥与开关（**.env 勿提交**） |

## 本地跑通（摘要）

1. `backend_clean`：配 `.env` → `python app.py`（`:5000`）  
2. `vue-ep-frontend`：`npm run dev`（`:5173`，`/api` 代理）  
3. 图谱库首次需 `scripts/import_to_mysql.py`；向量库一般已有 `chroma_db/`
